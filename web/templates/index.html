Mapa de bloques

Cada bloque es una carpeta o un archivo: cuanto más grande el bloque, más espacio ocupa. Pulsa una carpeta para entrar en ella y usa la ruta de arriba para volver.

El color de una carpeta es el del tipo de archivo que más espacio ocupa dentro de ella.
